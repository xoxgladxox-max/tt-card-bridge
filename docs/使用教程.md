# tt-card-bridge 使用教程（普通酒馆 & TauriTavern 通用）

`tt-card-bridge` 是一个把酒馆里的角色卡和世界书**拆成本地文件夹（`.md` 文件）**，并在**本地编辑器（VS Code / 记事本 / 任意 AI 工具）与酒馆之间实时双向同步**的插件。

- **独立可用**：内置完整的拆卡、装卡与格式校验核心，**不需要安装任何写卡技能库**。
- **双端兼容**：同时支持 **普通酒馆（原生 SillyTavern）** 与 **TauriTavern（TT 酒馆）**。
- **安全可控**：安装与同步全程**先识别环境、列出变动、询问确认后才执行**，绝不擅自改动你的配置或覆盖你的卡。

---

## 一、安装前准备

电脑上需要安装 **Node.js（20 或更高版本）**。
- 检查方法：打开终端（CMD 或 PowerShell）输入 `node -v`，能看到 `v20.x.x` 或更高版本号即可。
- 如果没装，去 [Node.js 官网](https://nodejs.org/) 下载 LTS 版本安装即可。

---

## 二、安装步骤（普通酒馆与 TT 酒馆通用）

> ⚠️ **注意**：不要只在酒馆网页里填 Git 链接点「安装扩展」。因为网页浏览器没有权限直接读写你电脑硬盘上的本地文件夹，必须通过下面的安装脚本同时装好「网页扩展」和「本机同步后台」。

### 1. 下载插件到本地
在你喜欢的位置打开终端，运行：
```bash
git clone https://github.com/xoxgladxox-max/tt-card-bridge.git
cd tt-card-bridge
```
（如果没有装 Git，也可以直接在 GitHub 页面点 `Code -> Download ZIP`，解压出来。）

### 2. 运行安装程序（先识别，确认后才安装）
- **Windows 用户**：直接双击文件夹里的 **`install.bat`**
- **命令行方式**：在 `tt-card-bridge` 目录下运行：
  ```bash
  node bin/tt-card.mjs install
  ```

运行后，程序**不会立刻写入任何文件**，而是先做一次**只读环境识别**，显示如下报告：
1. **酒馆环境识别**：
   - 自动检测本机的 **TauriTavern** 或 **普通酒馆（SillyTavern）**。
   - 如果你的普通酒馆放在别的盘、没被自动扫到，程序会提示你输入一次普通酒馆的 `default-user` 目录路径（例如 `D:\SillyTavern\data\default-user`），输入后会记住，以后不用再输。
   - 如果你电脑上同时装了 TT 酒馆和普通酒馆，会列出序号让你选择装到哪一个。
2. **依赖与组件检查**：
   - 如果缺少本地依赖包（`yaml`），会先询问你：`是否允许现在执行 npm install 安装依赖？ [y/N]`。
   - 列出将要安装的酒馆扩展路径、后台启动协议（`tt-card-bridge://start`），询问你：`是否确认按上述计划安装/更新？ [y/N]`。
3. 输入 **`y`** 回车确认后，几秒钟即可安装完成。

> 💡 如果你只想看看环境识别结果、不想做任何改动，可以运行：`node bin/tt-card.mjs install --check`

## 三、启动与设置工作区

1. 打开酒馆（如果安装时酒馆已经开着，按 **`Ctrl + R`** 刷新一下网页）。
2. 打开酒馆顶部的 **扩展（积木图标） → 卡工程同步**。
3. 点击面板右上角的 **「启动同步」**：
   - 浏览器/客户端会通过刚才登记的本机协议静默拉起同步后台（无黑框打扰）。
   - 状态行变成 **「已连接 · 实时同步中」** 即表示就绪。
   - 平时关掉酒馆网页或客户端后，本机后台会自动跟着退出，不会开机自启占内存。
4. **（可选）设置你的卡工程存放目录**：
   - 展开面板下方的 **「设置」** 折叠区。
   - 默认工作区目录是插件目录下的 `cards` 文件夹。你可以把它改成你习惯放卡的文件夹（比如 `D:\我的角色卡工程`），填好点 **「切换」** 即可。
   - ⚠️ 注意：工作区目录填的是**装所有卡的总文件夹**，不要填单张卡自己的文件夹。

## 四、日常使用：只有两个核心操作

面板平时只做两件事：**把酒馆里的卡拆出来**，或者**把本地文件夹连回酒馆**。

### 场景 1：把酒馆里已有的卡拆成本地文件夹（第一次用）

1. 在酒馆里点击打开你要编辑的那张角色卡（不能在群聊里）。
2. 在「卡工程同步」面板的「当前卡」一栏：
   - 如果这张卡带有正则、酒馆助手脚本、变量或小白X任务，面板会先列出**拆前清单**。
   - 默认全部勾选（拆成 `regex/`、`scripts/` 下的独立文件，方便用编辑器改代码）；不想拆出来的可以取消勾选（会原样保留在 `card.md` 里，合卡时同样完整带回）。
3. 点击 **「拆解当前卡」**：
   - 插件会把这张卡和它绑定的世界书拆解到 `<工作区目录>\<卡名>\` 文件夹下。
   - **拆完即自动连上，立刻进入实时双向同步！**

### 场景 2：开始改卡（实时双向同步）

连上之后，你不需要点任何「推送」或「拉回」按钮：
- **在本地改**：用 VS Code、记事本或 AI 打开 `<工作区目录>\<卡名>\` 里的 `.md` 文件，改完按 `Ctrl + S` 保存，**0.5 秒后自动同步进酒馆**（酒馆界面会自动热刷新，不用重启网页）。
- **在酒馆里改**：你在酒馆网页里直接改了角色描述、开场白或世界书条目并保存，**也会自动写回本地对应的 `.md` 文件**。
- **只跟当前打开的卡**：你在酒馆里切到哪张已拆解的卡，后台就自动跟哪张卡同步；没打开的卡不会乱动。

### 场景 3：断开后重连，或把本地卡工程装进酒馆

当你重启了酒馆、或者在下拉框里选了一个本地卡工程，点击 **「连接」** 时，有三种情况：

1. **这个本地文件夹从来没进过酒馆（比如刚用 AI 写好的新卡）**
   - 点击 **「连接」** 后确认，插件会按本地工程在酒馆里**新建一张角色卡 + 新建一本对应的世界书**（如果名字和酒馆里现有的重名，会自动加 ` 2`、` 3`，绝不覆盖旧卡和旧世界书），建好后**自动跳转到新卡**并开启实时同步。
2. **之前连过，且断开期间两边内容一致**
   - 直接恢复连接并跳转到该卡，继续实时同步。
3. **之前连过，但断开期间本地或酒馆改过了（两边不一致）**
   - 同步会自动停下，面板弹出两个选择：
     - **「以本地为准覆盖」**：把本地文件夹的内容整卡写进酒馆原来那张卡和它的世界书里（酒馆那边的未同步改动不保留）。
     - **「新建卡」**：**不动酒馆里原来的旧卡和旧世界书**（直接留在酒馆里当历史备份），按本地文件夹另建一张新卡（如 `卡名 2.png`）和一本新世界书，之后连着新卡同步。

> 💡 **怎么留历史版本备份？**
> 插件不做隐藏的后台自动备份文件夹。当你大改本地文件、怕改坏原卡时，重连时直接点 **「新建卡」**，酒馆里的旧卡就是最直观的历史版本，随时可以切回去玩。

### 场景 4：单独拆解世界书

如果你只想编辑某本没有绑在当前卡上的独立世界书：
1. 在酒馆的「世界书编辑器」里打开那本世界书。
2. 展开面板的 **「工作区」** 折叠区，点击 **「拆解世界书」**，就会拆到 `<工作区目录>\<世界书名>\` 并实时同步。

## 五、本地卡工程文件夹格式说明（不要破坏的结构）

只要保持下面这个目录结构，你不需要任何特定工具或写卡技能，怎么改都能正常同步：

```text
<工作区目录>/
  └── <卡名>/
        ├── card.md                      【必需】卡根配置：卡名、world（绑定的世界书名）等
        ├── description.md               角色设定正文（单槽字段，空的不会生成）
        ├── personality.md               性格（可选）
        ├── scenario.md                  场景（可选）
        ├── mes_example.md               对话示例（可选）
        ├── system_prompt.md             系统提示词覆盖（可选）
        ├── post_history_instructions.md 历史后指令 / JB（可选）
        ├── character.png                角色封面图（新建卡时自动嵌进去）
        ├── message/
        │     ├── 0.md                   主开场白（first_mes）
        │     ├── 1.md                   备选开场白 1
        │     └── 2.md                   备选开场白 2 ...
        ├── world_book/
        │     └── 任意子文件夹/           支持按「角色/地点/系统」建子文件夹分类
        │           └── 条目名.md         一条世界书一个 .md 文件
        ├── regex/                       拆出来的局部正则（.json 配置 + .html 替换内容）
        └── scripts/                     拆出来的酒馆助手脚本（.json + .js）、变量、小白X任务
```

### 改文件时的 3 个实用技巧：
1. **怎么改世界书条目的触发词、顺序、深度？**
   打开 `world_book/` 下的 `.md` 文件，文件最上方 `---` 包裹的是 YAML 设置区（包含 `title` 条目名、`order` 排序、`position` 插入位置如 `before_char` / `after_char` / `@D4`、`constant` 常驻、`keys` 触发词列表），`<!-- body -->` 下面是条目正文。改完保存即可同步。
2. **怎么在本地手建一条新的世界书条目？**
   直接在 `world_book/` 下新建一个 `xxx.md`，写上：
   ```markdown
   ---
   type: world
   title: 新条目名字
   order: 100
   position: before_char
   constant: false
   keys:
     - 触发词1
     - 触发词2
   ---

   <!-- body -->
   这里写世界书条目的正文内容……
   ```
   **不需要手写 `id` 或 `tavern.id`**，保存后后台会自动给它分配不冲突的编号并推到酒馆世界书里。
3. **可以在卡文件夹里放自己的笔记或草稿吗？**
   可以！在卡文件夹下建 `记录/`、`候选/`、`待归位/`、`note/` 文件夹，或者放 `调研.md`，插件在合成和同步时会**完全忽略它们**，既不会塞进卡里，也不会影响同步。

## 六、进阶：让 AI（Cursor / Claude Code / LimCode / TT 内置 Agent）直接帮你改卡

后台运行时，自带一个本地 MCP 服务器，地址是：
- **MCP 地址**：`http://127.0.0.1:18789/tt-bridge/mcp`
- **请求头（Headers）**：`Authorization: Bearer <你的本机令牌>`
  （令牌保存在 `tt-card-bridge/.runtime/connection.json` 的 `token` 字段里）

1. **如果你用的是 TauriTavern（TT 酒馆）**：
   - 安装时已经自动帮你把「卡工程（tt-card-bridge）」MCP 和「卡工程」Agent 档案登记好了，打开 TT 的 Agent 就能直接调用 14 个卡工程读写与校验工具。
2. **如果你用的是普通酒馆 + 外部编程 AI（如 VS Code + LimCode / Cursor / Claude Code）**：
   - 你甚至不需要配 MCP——直接用 VS Code 打开你的 `<工作区目录>\<卡名>` 文件夹，让 AI 直接改里面的 `.md` 文件，后台的 `fs.watch` 会自动把 AI 改好的内容实时同步进酒馆！
   - 如果想让外部 AI 调用拆卡（`disassemble_card`）或格式校验（`validate_card`、`validate_worldbook`）工具，把上面的 MCP 地址和 `Authorization` 请求头填进你的 AI 客户端 MCP 设置里即可。

## 七、常见问题与卸载

- **Q：为什么提示「酒馆里开着群聊，退出群聊后打开这张卡，同步才会开始」？**
  - A：群聊里同时有多张角色卡，为了防止误覆盖，群聊状态下暂停单卡同步，退回单人卡界面即可。
- **Q：我在本地改某个 `.md` 文件时把顶部 YAML 格式写坏了，会把酒馆里的卡搞坏吗？**
  - A：不会。只要有任何一个参与同步的文件格式校验不通过，后台会立刻停止本轮同步并在面板报错指出是哪个文件写坏了，你改回正确格式保存后会自动恢复同步。
- **Q：怎么卸载插件？**
  - A：在 `tt-card-bridge` 目录下运行：
    ```bash
    node bin/tt-card.mjs install --remove
    ```
    程序会先询问你确认，确认后自动停掉后台、清理注册表启动协议、备份并移除酒馆里的扩展文件（你的本地卡工程文件夹和酒馆里的角色卡完好无损）。
