# 卡工程同步插件（`tt-card-bridge`）酒馆用户使用教程

本插件可以把酒馆里的角色卡和世界书**拆成本地文件夹（`.md` 文本）**，让你在电脑上用记事本、VS Code 或任何 AI 改卡，**保存即自动同步回酒馆**。
- **普通酒馆（SillyTavern）和 TT 酒馆（TauriTavern）都能用**。
- **不需要额外安装任何写卡技能**，插件已内置完整拆装卡功能。

---

## 第一步：在酒馆里直接安装扩展

1. 打开酒馆，点击顶部菜单栏的 **「扩展」**（积木图标） → **「安装扩展」**（Install extension）。
2. 在弹出的 **「输入扩展程序的 Git URL 以安装」** 窗口中：
   - **第一行（Git URL）** 填入：
     ```text
     https://github.com/xoxgladxox-max/tt-card-bridge
     ```
   - **第二行（分支或标签名称）**：留空即可。
3. 点击 **「仅为我安装」**（或 **「为所有用户安装」**），等待酒馆提示安装成功。

---

## 第二步：双击一次 `install.bat` 开启本机文件夹读写权限（只需做一次）

因为网页里的扩展本身没有权限直接读写你电脑硬盘上的本地文件夹，第一次装好后需要双击一次扩展文件夹里的 `install.bat` 来配对本机后台：

1. 打开插件被安装到的文件夹：
   - **普通酒馆（点「仅为我安装」）**：`SillyTavern/data/default-user/extensions/tt-card-bridge`
   - **普通酒馆（点「为所有用户安装」）**：`SillyTavern/public/scripts/extensions/third-party/tt-card-bridge`
   - **TT 酒馆（TauriTavern）**：`TauriTavern/data/extensions/third-party/tt-card-bridge`（或 `data/default-user/extensions/tt-card-bridge`）
2. 双击里面的 **`install.bat`**：
   - 它会**先自动识别你的酒馆环境**并列出检测结果，**不会擅自改动任何东西**。
   - 如果提示缺少依赖或询问是否确认安装，输入 **`y`** 并回车即可。
3. 回到酒馆按 **`Ctrl + R`** 刷新页面，展开 **扩展 → 卡工程同步**，点右上角的 **「启动同步」**。
   - 状态变成 **「已连接 · 实时同步中」** 就全部准备好了！（平时关掉酒馆后，后台会自动退出，不会开机自启。）

---

## 第三步：选择你的卡文件夹放哪里（可选）

1. 在「卡工程同步」面板里，点开下方的 **「设置」**。
2. 在 **「工作区目录」** 填一个你用来放卡的总文件夹路径（比如 `D:\我的角色卡`），点 **「切换」**。
   - 以后你拆出来的每一张卡，都会自动放在 `D:\我的角色卡\<卡名>\` 下。

---

## 第四步：日常怎么用？（只有两个按钮）

### 用法 1：把酒馆里已有的卡拆出来改（第一次拆卡）
1. 在酒馆里打开你要改的那张角色卡（不能在群聊里）。
2. 在「卡工程同步」面板里，直接点 **「拆解当前卡」**（如果卡里有正则、脚本或变量，默认全勾拆成独立文件，也可以取消勾选留在 `card.md` 里）。
3. **拆完就已经自动连上了！**
   - 去你的工作区文件夹里打开 `<卡名>` 文件夹：
     - `description.md` 是角色描述
     - `message/0.md` 是第一句开场白，`1.md`、`2.md` 是备选开场白
     - `world_book/` 下面是所有世界书条目（一条一个 `.md` 文件）
     - `regex/` 和 `scripts/` 是拆出来的正则和脚本
   - **你在电脑上改完任何一个文件按 `Ctrl + S` 保存，0.5 秒后就会自动同步进酒馆；你在酒馆里直接改字保存，也会自动同步回本地文件！**

### 用法 2：把本地改好的卡（或新写的卡文件夹）连进酒馆
1. 打开面板里的 **「工作区」** 折叠区，在下拉框里选中你的卡文件夹。
2. 点击 **「连接」**：
   - **如果这是你本地新建的卡文件夹（还没进过酒馆）**：它会自动在酒馆里**新建一张角色卡 + 新建一本对应的世界书**（重名会自动加 ` 2`、` 3`，绝不覆盖旧卡），并**自动跳转到这张新卡**开启实时同步。
   - **如果之前连过，且两边内容一样**：直接连上并跳转到这张卡。
   - **如果断开期间你改过文件，两边不一样了**：面板会停下来让你二选一：
     - 点 **「以本地为准覆盖」**：用本地文件夹直接覆盖酒馆里原来那张卡和世界书。
     - 点 **「新建卡」**：**保留酒馆里原来的旧卡和旧世界书不动（当成历史备份）**，按你本地现在的文件夹另建一张新卡（如 `卡名 2`）和一本新世界书，之后连着新卡同步。

---

## 附：改本地文件夹时的注意事项

只要不破坏拆出来的文件夹名字（`card.md`、`message/`、`world_book/`、`regex/`、`scripts/`），怎么改正文都可以：
- **世界书条目 `.md` 文件**：最上面 `---` 之间是条目的触发词（`keys`）、顺序（`order`）、常驻（`constant`）、位置（`position`）设置，`<!-- body -->` 下面是条目正文。
- **想自己放设定笔记/草稿**：可以在卡文件夹里随便建 `记录/`、`候选/`、`note/` 文件夹或者放 `调研.md`，插件会自动忽略这些文件，不会塞进卡里。
