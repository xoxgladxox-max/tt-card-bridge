# tt-card-bridge · 卡工程实时同步与拆装卡（支持 TauriTavern & 原生 SillyTavern）

连接角色卡/世界书工程（`<工作区>/<卡名>/`）与 **TauriTavern** 或 **普通酒馆（原生 SillyTavern）** 的前端扩展与本机同步服务。
**内置完整拆卡、合卡、格式校验与实时双向同步（`src/forge/`）**，独立单仓库即可运行，**不需要安装任何外部写卡技能库**。拆出来的文件夹天然符合标准格式，用 VS Code、记事本或任何 AI 修改文件都会实时同步。

---

## 一、快速安装（先识别环境，再询问确认，不擅自修改）

1. 克隆本仓库：
   ```bash
   git clone https://github.com/xoxgladxox-max/tt-card-bridge.git
   cd tt-card-bridge
   ```
2. 双击 **`install.bat`**，或运行：
   ```bash
   node bin/tt-card.mjs install
   ```
   - 安装脚本会**先只读识别**本机环境：
     1. 识别酒馆类型（自动发现 TauriTavern 或同级/父级原生 SillyTavern；若未找到普通酒馆目录，会提示你输入一次 `SillyTavern/data/default-user` 路径）
     2. 检查本地依赖（`yaml`）是否已安装
     3. 检查酒馆前端扩展、`tt-card-bridge://start` 后台启动协议、TauriTavern MCP 档案（仅 TT）、可选写卡技能库状态
   - 列出所有缺失或待更新项后，**询问你是否确认安装**，确认后才会执行写入。
   - 如只需查看环境识别报告、不执行任何写入，可运行：
     ```bash
     node bin/tt-card.mjs install --check
     ```
3. 打开酒馆（或按 `Ctrl+R` 刷新网页），进入 **扩展 → 卡工程同步**，点击 **「启动同步」** 即可。关闭酒馆页面后，本机后台会自动随之退出，不设开机自启。

## 二、普通酒馆（原生 SillyTavern）与 TauriTavern 兼容性

| 功能 | TauriTavern | 普通酒馆（原生 SillyTavern） |
|---|---|---|
| **拆解当前卡 / 拆解独立世界书** | 支持 | 支持 |
| **连接本地卡工程 / 实时双向同步** | 支持 | 支持 |
| **不一致时「以本地为准覆盖」或「新建卡」** | 支持 | 支持 |
| **点面板「启动同步」拉起后台、关酒馆自动退出** | 支持 | 支持 |
| **本地 MCP 接口（`http://127.0.0.1:18789/tt-bridge/mcp`）** | 自动登记到 TT 内置 Agent | 可手动配入 Cursor / Claude Code / LimCode |
| **可选制卡技能库（`cf-card-*`）同步** | 检测到技能库并确认后可同步 | 不需要（拆装卡已内置） |

## 三、核心使用流程（只保留两个核心动作）

1. **酒馆里的卡 → 拆到本地文件夹（第一次用）**
   - 在酒馆打开一张角色卡，点面板上的 **「拆解当前卡」**（可勾选要把哪些正则、脚本、变量拆成独立文件，不勾的留在 `card.md`，合卡时都会完整带回）。
   - 拆完自动在 `<工作区>/<卡名>/` 生成标准卡工程并开启**实时双向同步**。
2. **本地文件夹 → 连到酒馆（含新建卡与重连）**
   - 在面板「工作区」下拉框选中本地卡工程，点 **「连接」**：
     - **没进过酒馆的工程**：按本地工程在酒馆新建一张卡和对应的世界书（重名自动加编号，不覆盖旧卡/旧世界书），自动跳转到新卡并开启实时同步。
     - **连过的工程**：两边一致就直接连上并跳转到该卡；两边不一致时停下，让你在 **「以本地为准覆盖」** 和 **「新建卡」** 之间二选一。
3. **持续连接期间的实时双向同步**
   - 本地改文件（500ms 防抖）自动推到酒馆；酒馆里改卡或世界书自动拉回本地。
   - 不做自动备份——酒馆里保留的旧卡本身就是历史版本；怕改坏时选「新建卡」即可。

## 四、标准卡工程文件夹结构

只要不破坏以下文件结构，不用任何写卡技能也能正常双向同步：

```text
<工作区目录>/<卡名>/
  card.md                      卡根：卡名、world（世界书名）、留在卡里的扩展设置
  description.md               角色描述（其他单槽字段同理：personality.md、scenario.md、system_prompt.md 等）
  message/0.md                 主开场白（first_mes），1.md 起为备选开场白（alternate_greetings）
  world_book/**/<条目>.md      世界书条目（支持子文件夹分组；新建条目可省略 id，同步时自动补齐）
  regex/<序号>-<名>.json+.html 拆出的正则设置与替换内容
  scripts/<序号>-<名>.json+.js 拆出的酒馆助手脚本、variables.json、xiaobaix-tasks.json
  character.png                封面图（可选，新建卡无封面图时使用默认封面）
```
> 文件夹里放 `调研.md`、`记录/`、`候选/`、`待归位/`、`note/` 等资料不会进卡，也不会干扰同步。

## 五、命令行与测试

```bash
node bin/tt-card.mjs install --check    # 只读识别环境与缺失项
node bin/tt-card.mjs install            # 识别并询问确认后安装/更新扩展
node bin/tt-card.mjs install --remove   # 询问确认后卸载扩展
npm test                                # 运行全部单元测试
```
